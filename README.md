# Курс на Европу — симулятор гравитационных манёвров

Браузерная игра в одном файле (`index.html`: HTML + CSS + JavaScript, без библиотек).
Нужно довести зонд до Европы через систему Юпитера, составив цепочку пролётов
у спутников Ио, Европы, Ганимеда и Каллисто.

## Запуск
- Локально: открыть `index.html` в браузере (работает на компьютере и телефоне).
- Онлайн: GitHub Pages — Settings → Pages → Branch `main`, папка `/ (root)`.

## Как играть
1. Выберите стартовую орбиту вокруг Юпитера.
2. Составьте цепочку пролётов: спутник, где встреча, с какой стороны, высота пролёта.
3. Для каждого шага сразу видны v∞, угол поворота, скорость до/после и новая орбита.
4. Настройте финал — торможение и захват у Европы.
5. Нажмите «Запустить»: анимация полёта, затем итог с очками.
6. Вкладка «Сравнение» — сохраняйте маршруты и сравнивайте по Δv, радиации, времени и очкам.
7. «Играть заново» или «Сбросить» — новая попытка.

## Критерии успеха
Захват у Европы, Δv ≤ 1,6 км/с, доза радиации ≤ 100 крад, время ≤ 600 суток.
Очки (0–100): 45 % запас по Δv, 30 % по радиации, 25 % по времени;
без захвата — 0, при нарушении критериев — ×0,4.

## Физическая модель
Метод сопряжённых конических сечений, плоская задача:
1. Вне спутников КА летит по кеплеровскому эллипсу вокруг Юпитера.
2. В системе спутника скорость v∞ не меняет модуль, но поворачивается на
   δ = 2·asin(1 / (1 + rп·v∞² / μ)), где rп = радиус спутника + высота пролёта.
3. Скорость после пролёта = V_спутника + повёрнутый v∞; по ней строится новая орбита.
4. У Европы тормозной импульс: Δv = √(v∞² + 2μ/rп) − v_орбиты захвата.

Допущения: круговые компланарные орбиты спутников; фаза спутника подгоняется
малыми коррекциями (0,02 км/с за встречу); радиация — условная экспоненциальная модель.

## Структура кода (`index.html`)
- `<style>` — адаптивные стили.
- Первый `<script>` — физика (`window.Physics`): орбиты, пролёт, захват, радиация, оценка.
- Второй `<script>` — интерфейс: план, canvas, анимация, итог, сравнение.
